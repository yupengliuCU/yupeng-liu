# CU ProSeminar deck (6 Nov 2026)

- `index.html` is the whole deck: one self-contained file (fonts and images inlined). Edit it directly and push to `main`; GitHub Pages serves it at https://yupeng-liu.com/talks/proseminar-cu-2026/.
- Slides are `<section class="slide">` blocks inside `<main id="deck">`, 1920 x 1080 canvas. Keys: arrows/space, f fullscreen, n notes; `?print` for PDF.
- Clicks: class `frag`; same `data-fg` number = same click.
- Part 3 (game project) goes where the `id="g-todo"` placeholder slide is, before `id="end"`.
- Style rules: see STYLE.md. The generator for the first version lives in the project files (proseminar_talk/build.py); after that, the repo file is the source.
